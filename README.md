# Jishnu S — Portfolio

A modern animated React portfolio built with Vite, Framer Motion and Lucide React.

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal → New Terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown by Vite.

## Build for deployment

```bash
npm run build
```

## Deploy with Vercel

Push the project to GitHub, then import the repository into Vercel.
Vercel will detect Vite automatically.
